## 1. 产品心智与入口

- 首发主表达（欢迎页 H1）：**按岗位，一键生成可投递简历**
- 辅助说明：提供真实经历和目标岗位，系统完成选材、表达与排版。你只需确认事实并对结果提出修改。
- 双冷启动：上传现有简历（Active · PDF）/ 我还没有简历（Design-only · 演示）
- 事实确认后汇合到同一任务：身份摘要 + JD → 一键生成 → 结果预览

## 2. 信息架构（已批准方向）

桌面 208px 稳定侧栏 + 任务工作区：

- 一级入口：生成简历、我的经历、个人与隐私（侧栏底部）
- 简历记录：长期预留，默认不作为可用生产入口（侧栏脚注说明）
- 开发者后台：隐藏独立入口（`个人与隐私` 下方 `开发者后台 ›`），普通导航不出现
- 窄屏（<900px）：侧栏折叠为顶栏 + 横排导航

页面/状态视图（同一 section 体系，按场景切换）：

`welcome（冷启动）→ upload（上传：idle / parsing / error / confirm）→ generate（资料就绪）→
processing（生成中：真实 4 阶段 + 已提交输入摘要）→ result（预览主从 + 依据 / 修改 / 导出）；
另有 experience（我的经历）、privacy（个人与隐私）、dev（开发者后台）、chat-empty（对话补充占位）`

## 3. 主题（固定 A）

**Product Owner 已选定 A 克制的职业工作台**（暖灰画布 + 白色工作面 + 深松绿 + 极少量暖铜），
界面不再提供 A/B/C 评审切换器；B/C 语义 token 集仍保留在本稿样式中，仅可用静默 URL
`?theme=B|C` 复核（界面上没有任何评审元素）。

| Token 语义 | A 数值 |
| --- | --- |
| canvas / surface | #F7F7F5 / #FFFFFF |
| border / border-strong（控件） | #D0D5D2 / #8A918D |
| primary / hover / focus | #1F5C4B / #184A3D / #2F7E68 |
| tint（选中底） | #E7F2EE |
| accent 暖铜（少量） | #C46A3D |
| ok / warn / error / info | #1B6B4A / #7A4B00 / #B42318 / #1D4ED8 |

排版：中文字体苹方/雅黑/Noto Sans SC 回退，正文 16/1.65 层级体系，正文左对齐不做两端对齐。
间距基于 4px：页面 32 / 容器 24 / 分组 32；控件高 44，重要主操作 48；文本域最小 220；圆角 8/12/16。
焦点环 2px `--focus` + 2px offset；行级操作目标 ≥ 32×32。状态不只靠颜色（chip 同时带文字/图标）。

## 4. 页面职责与状态

### 4.1 生成简历（默认任务）——默认一屏，无需整页滚动
- 身份摘要默认一行可见（姓名 · 电话 · 邮箱 · 所在地；姓名缺失行内红字提示）；点「编辑」按需展开输入区
- JD 大文本框为主输入（≥220px）；JD ≥60 字即显示「已理解 · 后台自动分析」摘要 chips
- 生成前检查只显示需要当前处理的项：阻断（姓名缺失 / 无可用于生成的经历 / JD 过短）、
  需确认（事实冲突）；无待处理项 → 面板隐藏，主按钮旁显示一行「事实与输入已就绪」
- 「暂不使用 / 质量建议」默认移到结果期（预览辅助区「初稿建议」、选中 bullet 后的「未采用说明」），
  不占用生成前空间
- 主按钮「生成岗位简历」仅在无阻断时可用；在 1440×900 下与身份摘要、JD 同屏可见
- 生成中：稳定任务标题、已提交输入摘要、4 个用户语言阶段（挑选相关事实 → 起草表达 → 排版装配 →
  完成装配）、已用时时；不支持虚构百分比
- 失败：输入保留、可理解的恢复动作（重新生成 / 返回修改）、诊断编号；Provider 等技术详情只在后台

### 4.2 结果预览（主从布局）
- 主区：固定比例纸张预览，放入区域内滚动容器（不拖长整页）；bullet 可选中
- 辅助区（sticky 360px）：意图输入 + 4 个建议意图（更突出项目 / 更技术 / 更简洁 / 强调真实成果）+
  作用范围说明；选中 bullet 后切到「依据」：原文事实 / 采用原因 / 对应经历 / 未采用说明
- 导出：DOCX（Active 能力，原型不产真实文件）+ 复制纯文本；事实纠正引导回「我的经历」

### 4.3 我的经历
- 列表（区域内滚动，筛选与操作行固定）+ 类型筛选（全部/教育/实习/项目/活动/技能/暂不使用）+ 搜索
- 每条含状态（已确认 / 需确认 / 暂不使用）、摘要与事实列表
- 新增 / 编辑 / 删除确认均可用；新事实不静默写入长期资产（演示）
- 空态提供上传 / 新增两个主操作

### 4.4 个人与隐私
- 数据保存位置、可靠性三层信息模型、缺失信息四级处理、清除演示数据（二次确认）

### 4.5 开发者后台（隐藏）
Provider 配置 / 数据库与索引 / 最近运行活动 / 诊断（仅评审与排障演示）

## 6. 默认进入态与评审约定（界面无评审工具）

- 默认（无参数）按真实产品状态进入：无可用于生成的经历 → 冷启动欢迎两路径；有经历 → 生成简历。
- 界面不出现任何评审工具；主题固定 A。
- 静默 URL 深链仅用于内部截图复现 / 状态复核：`?theme=A&sc=<scenario>`（scenario 见代码
  `SCENARIOS` 键），用户界面上不存在对应入口。

## 7. 可访问性与响应式

- 语义 HTML（nav/main/section/dialog/fieldset 等）、真实 label/button/input
- `:focus-visible` 焦点环、`aria-current` 导航态、弹窗焦点语义、toast aria-live
- `prefers-reduced-motion` 全局关闭过渡与动画
- 断点 <900px 侧栏折叠；<520px 纸张页头纵向
- 目标 viewport：1440×900 / 1280×800 / 1024×768 / 390×844 / 320×568；截图以 Chromium 1440×1100 为主
