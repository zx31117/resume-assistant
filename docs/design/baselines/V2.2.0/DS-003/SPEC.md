## 1. 目标与非目标

### 目标

以固定工作面承接高频生成，身份/JD只输入一次；已保存状态、返回任务、历史业务结果均清楚。验证完整Fact与旁侧理由，以及过程HTML向最终PDF切换。

### 非目标

不开发生产接口、模型、任务数据库、SSE或worker。HTML完成不代表上线，主题切换不是生产换肤。无新模板、身份自动回填、意图修订或无简历对话。

## 4. 核心旅程

### Journey J1 已有资料面向新JD生成

- 入口条件：fixture已有三段确认经历，打开空白任务。
- 用户目标：本次身份+岗位生成简历。
- 必要步骤：姓名/JD必填，电话/邮箱/所在地/目标岗位选填，点击生成。
- 系统自动完成：保存确认，P1业务项、P2入选结果、P3整条Fact和理由、P4样张。
- 用户必须确认：输入真实边界，无逐条采用或模板选择。
- 可跳过或降级：选填联系方式，未确认到岗安排不写入，重复项目不采用。
- 成功终点：固定PDF及对应Word/PDF下载。
- 中断与返回：导航/同标签刷新恢复，步骤1/2/3回看。
- 失败恢复：保留输入，重试经历或文件阶段。
- 能力缺口：DESIGN_ONLY，不测真实模型质量或性能。

### Journey J2 材料不足和事实纠正

- 入口条件：insufficient或理由旁发现事实需补充。
- 用户目标：补充事实后返回，不重填身份/JD。
- 必要步骤：我的经历→选择经历→写虚构补充→确认保存。
- 系统自动完成：保存本轮补充；阻断任务恢复输入态；不替换已完成文件。
- 用户必须确认：对象、内容、“用于后续任务，当前生成和已导出文件不自动改变”的范围。
- 可跳过或降级：无需编造数字，可以返回编辑。
- 成功终点：显示本轮补充，返回时身份/JD完整。
- 中断与返回：顶部返回当前任务；窄屏select切换经历。
- 失败恢复：空文字不保存；失败经历重试不丢失已完成实习。
- 能力缺口：DESIGN_ONLY，不进入真实Career Memory、不重制文件。

### Journey J3 成功预览、取消与新任务

- 入口条件：生成中或已完成。
- 用户目标：核对文件，或停止并重新开始。
- 必要步骤：运行中先取消；终态后开始空白任务；成功时可直接下载。
- 系统自动完成：取消后不再新增Fact；新任务清空姓名/联系方式/JD；已有记录留在内存。
- 用户必须确认：取消、新任务、清草稿的对象与影响。
- 可跳过或降级：取消默认焦点为“继续生成”；PDF失败保留Word样张下载。
- 成功终点：文件可下载或空白任务可立即填写。
- 中断与返回：我的简历查看固定样张记录。
- 失败恢复：PDF未就绪不提供PDF下载，支持文件重试。
- 能力缺口：DESIGN_ONLY，不证明Provider内部计算或计费撤销。

无依赖Tooltip的关键操作。详情弹窗导航先关闭弹窗。确认步骤Escape不替代显式选择；保留动作关闭后返回触发控件。JD最低30字符、maxlength12000仅为原型输入约束，不代替生产容量或有效性合同。

批注模式使用捕获阶段拦截点击，选择组件时不执行原操作。批注包含文本、组件选择器/标签、页面、scenario、主题、viewport、URL和时间；本地服务对内容和数量做上限校验，以临时文件替换方式写入 `review-annotations.json`。这是Design-only评审数据，不接生产API。批注标记仅在对应页面和场景中定位，无法定位时仍可从记录读取。

## 7. AI、事实和作用范围

| 动作 | 自动内容 | 确认内容 | 影响范围 | 反馈 |
|---|---|---|---|---|
| 输入 | 本地保存 | 输入本身 | 当前任务 | 正在保存/已保存 |
| 生成 | 整条Fact后出现，理由旁侧逐字 | 无逐条采用 | 当前简历模拟 | 完成计数与原文 |
| 补充事实 | 保存显式文字 | 对象和后续影响 | 经历模拟记录 | 当前文件不变 |
| 清草稿 | 清身份/JD | 确认清除 | 当前草稿 | 保留经历/记录 |

理由是fixture业务解释，不是模型内部思维，不展示评分或置信度。Fact仅headline及冒号加粗；教育字段分开，技能三类有来源；JD到岗要求不写成个人事实。

## 8. 状态模型与恢复

| 状态 | 用户看到 | 主操作 | 次操作 | 输入保留 | 技术详情 |
|---|---|---|---|---|---|
| Default/Empty | 空白或已保存 | 生成 | 编辑/经历 | 保存成功部分 | 评审工具 |
| Loading | P1/P2业务项，P3Fact/理由，P4文件 | 等待 | 取消/回看/导航 | 是 | 设计说明 |
| Blocked | 缺确认个人贡献 | 补充经历 | 返回输入 | 是 | 不展示内部实现 |
| Error | 指定经历或PDF失败 | 相应范围重试 | 可用Word下载 | 是 | 虚构诊断编号 |
| Partial | 实习完成，项目未完成 | 重试项目 | 回看 | 是 | 设计说明 |
| Cancelled | 取消前已完成内容 | 修改/新任务 | 回看 | 是 | 设计说明 |
| Success | 最终PDF及双下载 | 下载 | 记录/新任务 | 同服务期间 | 设计说明 |

本稿180ms轮询服务内存，非真实SSE。750ms输入防抖后发保存请求，仅回执成功才清dirty。sessionStorage保存任务引用，不长期保存Profile。服务重启后原任务消失；关闭标签再重开的发现未实现。此行为不可作为生产能力声明。
