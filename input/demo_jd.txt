岗位标签：示例岗位（虚构，不代表任何真实公司或职位）

公司名称：星辰科技（虚构名）
岗位：高级后端研发工程师（Java）
地点：杭州

岗位职责：
1. 负责电商平台核心交易链路的系统设计、编码实现与线上保障；
2. 主导关键业务模块的架构演进与性能优化，确保高并发场景的稳定性；
3. 与产品、前端、QA 团队高效协作，推动需求高质量按时交付；
4. 持续完善后端基础能力，提升团队整体研发效率。

岗位要求：
1. 本科及以上学历，计算机相关专业，3–6 年后端开发经验；
2. 扎实的 Java 基础，精通 Spring Boot / MyBatis 等主流框架；
3. 熟悉 MySQL、Redis、MQ 等常用中间件，具备调优与问题排查能力；
4. 有高并发、高可用系统开发经验，了解分布式事务、缓存一致性等问题；
5. 良好的沟通与协作能力，具备较强的责任心和抗压能力。
